# ParaBear Assets

Use this folder for source artwork and exported UI assets for ParaBear.

Suggested organization:

```text
Assets
├─ Bear
│  └─ bear.svg
├─ parachute.svg
├─ MenuBarLogo
└─ AppIcon
```

Guidelines:

- Keep source files and exported app-ready files separate.
- Prefer transparent-background PNG, PDF vector, or SVG source files.
- Export at high resolution so the bear stays crisp on Retina displays.
- Keep the bear and parachute as separate SVG assets.
- Keep the parachute canopy and rigging in the same source SVG so they stay visually connected.
- Keep the menu bar logo simple enough to work as a monochrome template icon.
- App icon artwork should be prepared at 1024x1024 first, then exported into the standard macOS icon sizes.
