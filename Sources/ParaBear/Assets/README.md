# ParaBear Assets

Use this folder for source artwork and exported UI assets for ParaBear.

Suggested organization:

```text
Assets
├─ Bear
│  ├─ calm
│  ├─ alert
│  └─ urgent
├─ Parachute
├─ Rigging
└─ Exports
```

Guidelines:

- Keep source files and exported app-ready files separate.
- Prefer transparent-background PNG, PDF vector, or SVG source files.
- Export at high resolution so the bear stays crisp on Retina displays.
- Keep bear, parachute, and rigging as separate layers/assets so animation can control them independently.
